Exercice 1 : Comparaison de deux moyennes (t-test)

Contexte

On cherche à valider un nouveau substrat à base de mélasse de canne pour optimiser la production d’acide citrique par Aspergillus niger. On compare les rendements obtenus (\(g/L\)) dans 12 bioréacteurs indépendants pour chaque condition.

Données et Test

Voici le script pour charger les données et exécuter le test \(t\) de Student pour échantillons indépendants.

# Données de rendement (g/L)
classique <- c(64.2, 65.5, 61.8, 68.1, 63.9, 66.2, 60.4, 67.3, 62.1, 69.0, 64.5, 68.3)
melasse   <- c(76.5, 78.1, 72.4, 82.3, 79.0, 75.6, 84.1, 77.8, 80.5, 73.9, 81.2, 79.4)

# Affichage des moyennes et écarts-types
cat("Substrat Classique - Moyenne :", mean(classique), "SD :", sd(classique), "\n")
Substrat Classique - Moyenne : 65.10833 SD : 2.783869 
cat("Substrat Mélasse   - Moyenne :", mean(melasse), "SD :", sd(melasse), "\n\n")
Substrat Mélasse   - Moyenne : 78.4 SD : 3.430611 
# Exécution du t-test (variance égale supposée)
test_results <- t.test(melasse, classique, var.equal = TRUE)
print(test_results)

Exercice 2 : Comparaison de plusieurs moyennes (ANOVA)

Contexte

Vous testez l’effet de 4 sources d’azote différentes (Ammonium, Nitrate, Urée, Peptone) sur le taux de croissance spécifique \(\mu_{max}\) (\(h^{-1}\)) de Saccharomyces cerevisiae en fermenteur. Vous disposez de 5 réplicats biologiques indépendants par condition.

Données et Test

Exécutez le bloc de code ci-dessous pour effectuer l’ANOVA unidirectionnelle (One-way ANOVA) et le test post-hoc de Tukey.

# Création du jeu de données
donnees_growth <- data.frame(
  Source = factor(rep(c("Ammonium", "Nitrate", "Uree", "Peptone"), each = 5)),
  Mu = c(0.35, 0.38, 0.36, 0.34, 0.37,  # Ammonium
         0.21, 0.24, 0.22, 0.25, 0.23,  # Nitrate
         0.28, 0.30, 0.29, 0.31, 0.27,  # Urée
         0.45, 0.48, 0.46, 0.44, 0.47)  # Peptone
)

# ANOVA
modele_anova <- aov(Mu ~ Source, data = donnees_growth)
summary(modele_anova)

  • Df (Source) = \(k - 1 = 3\) (degrés de liberté inter-groupes).
  • Df (Residuals) = \(N - k = 16\) (degrés de liberté intra-groupes/résiduels).
  • F value = Statistique du test de Fisher (\(F\)).
  • Pr(>F) = La \(p\)-value globale de l’ANOVA.

Règles d’or pour vos rapports et mémoires

  1. Ne masquez jamais les données brutes : Accompagnez toujours vos moyennes (\(M\)) de leur dispersion (Écart-type \(SD\)).
  2. Soyez précis : Écrivez la valeur exacte de votre statistique de test (\(t\) ou \(F\)), ses degrés de liberté entre parenthèses, et la valeur exacte de \(p\) (ex: \(p = 0,014\) plutôt que \(p < 0,05\)).
  3. Mise en forme : En français scientifique, utilisez la virgule pour les décimales. Les symboles statistiques (\(M, SD, t, F, p\)) s’écrivent toujours en italique.
